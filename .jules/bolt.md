## 2024-05-18 - Avoid Next.js Image component when src is external and loader isn't configured
**Learning:** In Next.js, while `<Image />` is generally preferred for performance, it requires specific configuration (like `next.config.js` domains/remotePatterns) for external URLs like `https://img.icons8.com/` or `https://ghchart.rshah.org/`. Without this setup, it's safer and easier to use native `<img>` tags with `loading="lazy"` and `decoding="async"` for offscreen images to improve performance without requiring architectural or config changes.
**Action:** Use native `loading="lazy"` on external `<img>` elements when `next/image` is not an easy drop-in replacement due to missing config, especially when following strict "no breaking changes" and "no new dependencies/config" rules.
